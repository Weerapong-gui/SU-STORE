# /display2 Per-Station Fulfillment Display — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an internal `/display2` page where workers at three product stations (Polo / Jacket / Headband) see a live, shared queue of items pushed from claim-station, tap a check to mark each picked, and review/undo today's picks from a history modal.

**Architecture:** New SQLite table `display2_picks` storing one row per item per order; backend hook inside the existing `/claim-station/orders/<code>/received` handler enqueues rows; new HTTP endpoints serve queue / pick / undo / history; single-page HTML template polls every 2 s. Reuses claim-station login. Spec: `docs/superpowers/specs/2026-06-25-display2-design.md`.

**Tech Stack:** Python `http.server` (raw), SQLite (stdlib), vanilla HTML/CSS/JS (no framework). Tests use stdlib `unittest` (no install needed).

## Global Constraints

- File ownership: all backend changes go in `server/order_api.py`. Frontend in `server/templates/display2.html`.
- Bangkok timezone (`+7 hours`) for any date filter; UTC stored in DB via `now_iso()`.
- Reuse `_has_claim_station_authorization` for every endpoint except the page route.
- **No emoji in the actual UI** — use inline SVG icons (per project memory `feedback_no_emoji`). Emoji in this plan inside mockups or labels are illustrative only; the final UI must use SVG.
- Station slugs: `polo`, `jacket`, `headband`. Mapping from `product_slug`: `single → polo`, `jacket → jacket`, `headband → headband`.
- Polling interval: 2 s. Undo window: 1 hour from `picked_at`.
- Deploy: `bash deploy-api.sh` (order-api only) after the plan is complete. Per-task commits do not deploy.
- Pre-deploy verification: `python3 -c "import ast; ast.parse(open('server/order_api.py').read())"` must pass.

```python
STATION_BY_SLUG = {
    "single": "polo",
    "jacket": "jacket",
    "headband": "headband",
}


def enqueue_display2(connection, order_row, claim_user):
    """Insert one display2_picks row per item in the order, mapped by product_slug.
    Idempotent on (order_internal_id, item_index). Returns count of new rows."""
    try:
        items = json.loads(order_row["items_json"] or "[]")
    except (TypeError, json.JSONDecodeError):
        items = []
    if not items:
        items = [{
            "slug": order_row["product_slug"],
            "name": order_row["product_name"],
            "size": order_row["size"],
            "quantity": order_row["quantity"],
        }]
    inserted = 0
    now = now_iso()
    for idx, item in enumerate(items):
        slug = (item.get("slug") or "").lower()
        station = STATION_BY_SLUG.get(slug)
        if not station:
            log_audit(connection, order_row["order_code"],
                      "display2_skipped", f"slug={slug} item={idx}")
            continue
        exists = connection.execute(
            "SELECT 1 FROM display2_picks WHERE order_internal_id=? AND item_index=?",
            (order_row["internal_id"], idx),
        ).fetchone()
        if exists:
            continue
        connection.execute(
            """INSERT INTO display2_picks
               (order_internal_id, order_code, item_index, station,
                product_slug, product_name, size, quantity,
                student_code, nickname, full_name, queued_at, queued_by)
               VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?)""",
            (order_row["internal_id"], order_row["order_code"], idx, station,
             slug, item.get("name", ""), item.get("size", ""), int(item.get("quantity", 1) or 1),
             order_row["student_code"], order_row["nickname"], order_row["full_name"],
             now, claim_user),
        )
        inserted += 1
        log_audit(connection, order_row["order_code"],
                  "display2_enqueued", f"station={station} item={idx}")
    return inserted
```

        if path == "/display2/pick":
            if not self._has_claim_station_authorization():
                self._deny_unauthorized()

                payload = self._read_json()

                log_audit(connection, row["order_code"], "display2_picked",

            + '&q=' + encodeURIComponent(q),
          { headers: authHeaders() })
